# 活动管家 - 智能活动筹备管理系统

## 第一部分：管理员使用指南

### 项目启动

```bash
# 安装依赖
npm install

# 开发模式启动
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

开发服务器默认运行在 `http://localhost:5173`

数据库、Supabase Edge Functions 和 Vercel 上线步骤见 [`docs/deployment.md`](docs/deployment.md)。

### 系统功能概览

| 模块 | 功能说明 |
|------|----------|
| **仪表盘** | 查看活动统计、即将到来的活动、团队工作量分布 |

#### 如何修改/新增模板和任务

**文件路径：** `src/lib/task-templates.ts`

**新增任务库任务：**
在 `TASK_LIBRARY` 数组中添加对象：

```typescript
{
  id: 'unique-task-id',           // 唯一标识
  title: '任务标题',
  description: '任务描述',
  defaultDaysBeforeEvent: 7,      // 活动前多少天截止
  defaultPriority: 'high',        // high/medium/low
  suggestedRole: '建议负责人角色',
  category: '分类名称',            // 如：流程、场地、宣传
}
```

**修改活动模板：**
在 `EVENT_TEMPLATES` 数组中编辑对应模板的 `taskIds` 数组：

```typescript
{
  id: 'template-id',
  name: '模板名称',
  icon: 'Lucide图标名',           // 如：Presentation、Users
  description: '模板描述',
  taskIds: ['task-id-1', 'task-id-2', ...]  // 引用任务库中的任务ID
}
```

**新增活动模板：**
在 `EVENT_TEMPLATES` 数组末尾添加新对象，参考现有模板格式。

### 飞书集成配置

系统支持通过飞书群机器人发送任务提醒。

**配置步骤：**

1. 在飞书群聊中点击「设置」→「群机器人」→「添加机器人」
2. 选择「自定义机器人」，设置名称和头像
3. 复制生成的 Webhook 地址
4. 在系统「设置」页面粘贴 Webhook 地址并保存
5. 点击「测试」按钮验证连接

**提醒规则设置：**

在「设置」页面可配置多个提醒规则，例如：
- 提前 7 天，每天 09:00 发送提醒
- 提前 3 天，每天 09:00 发送提醒
- 提前 1 天，每天 09:00 发送提醒

系统会在指定时间通过飞书机器人 @任务负责人。

### 数据存储说明

**存储方式：** 浏览器 localStorage 本地存储

**数据内容：**
- 所有活动数据（`qoder-events`）
- 团队成员数据（`qoder-members`）
- 飞书配置（`qoder-feishu-config`）

**重要注意事项：**

| 注意项 | 说明 |
|--------|------|
| 数据持久化 | 数据保存在浏览器本地，关闭页面不会丢失 |
| 浏览器限制 | 清空浏览器缓存/数据会导致所有数据丢失 |
| 多设备同步 | 不同浏览器/设备间数据不互通 |
| 备份建议 | 重要活动数据建议定期手动备份 |
| 隐私安全 | 数据仅存储在本地，不会上传到服务器 |

## 第二部分：同事使用指南

### 如何创建活动

创建活动分为三个步骤：

#### 步骤一：选择活动模板

1. 点击左侧导航「创建活动」
2. 浏览 6 种活动模板：
   - 企业会议、线下沙龙、展览/市集
   - 团建活动、年会、自定义活动
3. 点击选择适合的模板，查看包含的任务数量
4. 点击「下一步」

#### 步骤二：填写活动信息

填写以下基本信息（带 * 为必填）：

| 字段 | 说明 | 示例 |
|------|------|------|
| 活动名称 * | 活动的正式名称 | 2026年Q2全员大会 |
| 活动主题 | 活动主题口号 | 聚力前行·共创未来 |
| 开始日期 * | 活动举办日期 | 2026-05-01 |
| 结束日期 | 活动结束日期（可选） | 2026-05-01 |
| 活动地点 | 具体地点 | 公司三楼大会议室 |
| 活动描述 | 活动内容简介 | 简要描述活动内容和目标 |

填写完成后点击「下一步」。

#### 步骤三：编辑任务列表

系统会根据模板自动生成任务清单，你可以进行以下操作：

**1. 删除不需要的任务**
- 点击任务右侧的垃圾桶图标删除

**2. 从任务库添加任务**
- 点击「从任务库添加」按钮
- 按分类浏览所有可用任务
- 点击任务卡片添加到当前列表
- 已添加的任务会显示勾选标记

**3. 手动新增自定义任务**
- 点击「自定义新任务」按钮
- 输入任务标题
- 设置截止天数（活动前多少天）
- 选择优先级（紧急/重要/一般）
- 点击「添加」

**4. 编辑任务详情**
- **修改标题**：点击任务标题即可编辑
- **修改优先级**：点击优先级下拉框选择
- **调整截止天数**：修改数字输入框，系统会自动计算实际日期

**5. 调整任务顺序**
- 点击任务左侧的「↑」「↓」箭头调整排序

确认无误后，点击「确认创建活动」完成创建。

### 如何管理已有活动的任务

#### 进入活动详情

1. 在「仪表盘」点击活动卡片
2. 或在「任务面板」点击任务所属的活动名称

#### 任务操作

| 操作 | 方法 |
|------|------|
| **修改任务标题** | 点击任务标题文字，输入新标题后按回车或点击别处保存 |
| **修改截止日期** | 点击日期显示区域，选择新日期后自动保存 |
| **修改优先级** | 点击优先级标签（紧急/重要/一般），选择新优先级 |
| **删除任务** | 点击任务右侧垃圾桶图标，确认后删除 |
| **切换任务状态** | 点击左侧状态图标，循环切换：待开始 → 进行中 → 已完成 |
| **分配负责人** | 点击「分配」按钮，自动分配给第一个成员（需在团队成员页面添加成员） |

**任务状态说明：**
- ⭕ 待开始（灰色）
- ▶️ 进行中（橙色）
- ✅ 已完成（绿色）
- ⚠️ 已逾期（红色，自动标记）

### 如何使用任务看板

点击左侧导航「任务面板」进入任务总览：

**功能：**
- 查看所有活动的全部任务
- 按状态筛选：全部 / 待开始 / 进行中 / 已完成
- 按成员筛选：查看特定负责人的任务
- 搜索任务：输入关键词快速查找

**任务卡片显示：**
- 任务标题和优先级
- 所属活动名称
- 负责人头像和姓名
- 截止日期（逾期会标红）

**快捷操作：**
- 点击状态图标可快速切换任务状态

### 常见问题和注意事项

#### 数据安全

| 问题 | 解答 |
|------|------|
| 数据会丢失吗？ | 正常关闭浏览器不会丢失，但清空缓存会丢失所有数据 |
| 换了电脑能访问吗？ | 不能，数据存储在本地浏览器中 |
| 如何备份数据？ | 目前需要手动记录重要信息，建议定期导出关键数据 |

#### 使用技巧

1. **任务逾期提醒**：逾期任务会自动标红，优先处理
2. **快速创建活动**：选择相近的模板可以节省大量时间
3. **任务复用**：常用任务已内置在任务库，可直接添加
4. **团队协作**：在「团队成员」页面添加同事，便于分配任务

#### 飞书通知

- 需要先在「设置」页面配置 Webhook 才能接收通知
- 确保成员的「飞书 ID/邮箱」填写正确
- 提醒规则可按需配置多个

#### 浏览器建议

- 推荐使用 Chrome、Edge、Safari 等现代浏览器
- 请勿在无痕/隐私模式下长期使用（数据可能无法持久化）
